# Constructor de pitch

Aplicación web estática para construir y consolidar un pitch de hasta 15 minutos.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` a la raíz del repositorio.
3. Entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`. Guarda los cambios.
6. Espera a que GitHub Pages publique el sitio. La URL aparecerá en esa misma sección.

No requiere Node.js, instalación de dependencias ni proceso de compilación. Es una página HTML, CSS y JavaScript estática.

## Datos y privacidad

Las respuestas se guardan en el almacenamiento local (`localStorage`) del navegador y dispositivo donde se usa la herramienta. No se envían a un servidor ni se sincronizan automáticamente entre dispositivos. Si se borran los datos del sitio/navegador, se pueden perder las respuestas guardadas.
